\# Agent Evaluation Test Results



\## 1. 테스트 목적



OWASP 기반 RAG Agent가 사용자의 보안 관련 질문을 적절하게 처리하고, 검색된 OWASP 문서를 기반으로 답변을 생성하는지 확인하였다.



또한 계산 기능과 일반적인 보안 질문에 대한 응답도 함께 테스트하였다.



\## 2. 테스트 환경



\* LLM: Gemini 3.6 Flash

\* RAG: ChromaDB

\* 문서: OWASP 보안 문서

\* 개발 환경: Python / Spyder

\* Embedding 및 문서 검색: ChromaDB 기반 Retriever

\## 4. 테스트 결과 분석



보안 관련 질문에 대해 Agent가 ChromaDB에 저장된 OWASP 문서를 검색하고, 검색 결과를 Gemini에 전달하여 최종 답변을 생성하는 것을 확인하였다.



SQL Injection, XSS, CSRF 및 비밀번호 저장과 관련된 질문에서 각각 관련 OWASP 문서가 검색되었으며, 답변에 해당 문서의 출처가 표시되었다.



또한 계산 질문에 대해서는 `2 + 3 \* 4 = 14`라는 올바른 결과를 반환하여 비보안성 질문도 처리할 수 있음을 확인하였다.

\## 6. 결론



테스트 결과, 구현한 Agent는 OWASP 문서를 기반으로 보안 관련 질문에 답변하고, 검색된 문서의 출처를 제시하는 RAG 기반 질의응답 기능을 정상적으로 수행하였다.



또한 계산 질문에 대해서도 정상적인 결과를 반환하여 보안 문서 검색 외의 기능도 함께 동작함을 확인하였다.
